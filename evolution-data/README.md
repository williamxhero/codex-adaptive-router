# Adaptive Router evolution data

This directory is generated by the user-level sync job. It contains only privacy-bounded routing metadata: hashed identifiers, route/outcome evidence, policy revisions, and shadow evaluation state. Raw prompts, paths, source, tool output, logs, credentials, and secrets are rejected.

Immutable event v2 and v3 batches may coexist. Metrics normalize both schemas before aggregation. New artifacts use explicit LF bytes; already published immutable artifacts are never rewritten or newline-normalized.
